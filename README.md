# 🍕 Alessio's Pizzaria

### Projeto de desenvolvimento web para uma pizzaria

## 📌 Sobre o projeto

O Alessio's Pizzaria é um projeto desenvolvido durante meus estudos de desenvolvimento web, com o objetivo de praticar a criação e a estilização de páginas utilizando HTML e CSS.

O projeto apresenta uma página temática para uma pizzaria, trabalhando a organização dos elementos visuais e a apresentação de conteúdo em uma página web.

## 🌐 Acesse o projeto

🔗 **[Visualizar Alessio's Pizzaria](https://davidalvesjr.github.io/alessios-pizzaria/)**

## 🛠️ Tecnologias utilizadas

- HTML
- CSS

## 📂 Estrutura do projeto

- `index.html` — Estrutura principal da página.
- `style.css` — Estilização e apresentação visual.
- Arquivos de imagem — Recursos visuais utilizados no projeto.

## 🎯 Objetivo de aprendizagem

Praticar os fundamentos do desenvolvimento web, desenvolvendo habilidades de estruturação de conteúdo com HTML e estilização com CSS.
